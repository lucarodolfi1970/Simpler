SIMPLER SETUP
=============
What it does: a single Setup.exe with a wizard in Italian and English (the language of Windows): Simpler's license
agreement (in both languages) with specific approval of the clauses, a "Your computer" page (graphics card found and
how suitable it is), program folder, contents folder (with a check of the free space), desktop icon, installation
of WebView2 if missing, start of Simpler at the end. Inside: Simpler (with .NET included), the engine, Blender, the
two sample projects, the thumbnails of the cloud models, Simpler's decals. No models: they are downloaded on
request. Simpler's materials are made by the engine. Pack Studio is not included.

How to build it (Luca)
  1. Inno Setup installed (once).
  2. Double-click Build-Setup.bat in this folder. The window shows 7 steps; the last one takes 10-20 minutes.
  3. Write "done" to Claude: all the details are in build.log (Claude reads it).
  The result is in "Simpler setup\Output\Simpler-Setup-<version>.exe". The version is the one in Simpler.csproj.

Where it takes things from
  - thumbnails: M:\3D\simpler-setup\thumbs (made by Pack Studio when it prepares the cloud contents)
  - decals: the "Simpler" folder of Luca's decals (paths.json) -> the user's %APPDATA%\Simpler\decals\Simpler
  - agreement: credits\Licenza.md and credits\en\License.md; its version is LicenseWindow.Version
  - Blender: the one in Program Files\Blender Foundation (or: Build-Setup.bat "C:\folder\of\Blender")

Signature (when the certificate is there)
  Create the file "Simpler setup\sign.cmd" with ONE line, the signing command of the Certum certificate, with $f in
  place of the file. Example (to adapt to what Certum/SimplySign says):
     signtool.exe sign /fd SHA256 /tr http://time.certum.pl /td SHA256 /n "Name on the certificate" $f
  If the file is not there, the setup is built without a signature (Windows will show the SmartScreen warning).

After the installation the program is in %LOCALAPPDATA%\Programs\Simpler (or in Program Files if "for all users"
is chosen). Uninstalling does NOT delete the user's contents. The setup writes %APPDATA%\Simpler\license-accepted.txt:
Simpler does not ask for the agreement again at the first start.
