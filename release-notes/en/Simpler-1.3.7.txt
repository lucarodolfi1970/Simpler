SIMPLER 1.3.7  —  21 October 2026
=================================

NEW
---
- CHANGING A LIBRARY'S FOLDER, step by step (Settings > Folders > "Change…"):
  1. choose the new, empty folder (if it isn't empty, Simpler asks whether to use it as it is because it already
     holds a copy of the library, or to choose another one);
  2. Simpler asks whether it should move all the content itself, with all the subfolders (it shows how many files
     and how many GB);
  3. the copy starts with a progress bar (files, GB, current file) and can be cancelled;
  4. at the end every file is checked: only if the copy is complete does Simpler switch to the new folder
     (if it fails or you cancel it, it keeps using the previous one, nothing breaks);
  5. finally it asks whether it should delete the old folder itself or whether you prefer to leave it and delete it
     yourself after checking that everything works.
  When you move the Poly Haven materials, the Poly Haven 3D models (which are inside the same folder) follow too.
